Arc PAYG Calculator instructions

Start here

Use this discussion model to compare current SPLA licensing costs with Azure Arc PAYG for SQL Server and Windows Server. The currency selected on the Pricing tab applies to both calculator tabs.

Validate pricing, licensing rules, partner eligibility, incentive caps, and current program terms before using results in a reseller or customer offer.

How to use the calculator

  1. Open Pricing, select a currency, and enter the partner's monthly SPLA two-core pack prices.
  2. Review Azure PAYG pricing and its last refresh time on the Pricing tab.
  3. Open SQL Server PAYG or Windows Server PAYG, add workloads, select the edition and uptime profile, and enter total SQL cores or Windows VM counts and vCores.
  4. Configure incentives for SPLA, PEC, MCI, Growth Accelerator, and Direct DCO.
  5. Export calculation to save a named project, or import one to restore its prices, workloads, and incentive settings.
  6. Save offline copy on the GitHub Pages site to download the complete calculator as a standalone HTML file.
  7. Review results for monthly and annual costs, the three-year cost comparison, and total economic impact including incentives.

Calculation principles

  • SPLA inputs are monthly prices per two-core pack; the calculator converts them to a per-core monthly rate.
  • Azure PAYG inputs are per-core hourly rates from the Azure Retail Prices API and are embedded by the monthly GitHub Actions refresh.
  • For SQL Server, enter total SQL cores. The calculator enforces a minimum of four cores for each SQL workload row for both SPLA and PAYG.
  • Windows Server applies an eight-core minimum per VM for SPLA and a one-core minimum per VM for PAYG.
  • Uptime profiles convert to monthly hours; calculations retain full precision and round only for display.

Scope and limitations

  • The model supports SQL Server Standard and Enterprise core licensing, plus Windows Server Standard and Datacenter.
  • It does not model SQL Enterprise or Windows Datacenter unlimited virtualization on physical hosts, nor workloads shared by multiple end customers.
  • Azure prices outside USD can vary with exchange-rate updates. Check the displayed refresh time and verify current SPLA prices with the partner.
  • Incentives depend on partner eligibility, onboarding, maximum earning opportunity, and current program terms.
  • This calculator is non-binding. Independently verify results before making an offer.
